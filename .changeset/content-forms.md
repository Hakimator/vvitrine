The Studio edits your content: every content key has a form, with every language side by side and the file each one
is saved to. Fields missing in one language are marked, problems show under their field as you type and block saving,
lists can grow and shrink, and undo, redo and save have keyboard shortcuts. An edit session back to the saved content
has nothing left to save. The integration prepares the Studio's browser libraries when the dev server starts.
